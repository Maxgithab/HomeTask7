Описание классов программы Java Core

**AppMain**
Точка входа в программу. Управляет меню, загружает счета, вызывает сервисы для обработки файлов и вывода отчётов.

**Account**
Модель банковского счета. Хранит номер счета и текущий баланс.

**Transaction**
Модель денежного перевода. Хранит информацию о переводе: откуда, куда, сумма, статус выполнения и сообщение об ошибке.

**TransferException**
Пользовательское исключение для обработки ошибок, связанных с переводами.

**ParserService**
Сервис для чтения и парсинга файлов с переводами. Ожидает формат: три строки (счет списания, счет зачисления, сумма).

**TransferService**
Сервис выполнения переводов. Проверяет корректность перевода (формат счетов, существование счетов, достаточность средств) и обновляет балансы.

**ReportService**
Сервис для работы с отчётами. Записывает информацию о переводах в файл и выводит историю операций.

**FileUtils**
Утилитарный класс для операций с файлами. Содержит методы для чтения, записи, перемещения файлов, а также для загрузки и сохранения данных счетов.

**Validator**
Утилитарный класс для проверок. Содержит методы для валидации формата номера счета, суммы, существования счета и достаточности средств.
